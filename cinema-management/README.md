# Cinema Management App

A React Native Expo app for managing cinema with CRUD operations and authentication, connected to a MySQL database.

## Setup

### Backend
1. Install dependencies: `npm install`
2. Set up MySQL database using `travelgo_db.sql`
3. Configure `.env` with your database credentials
4. Run: `npm start`

### Mobile
1. Install dependencies: `npm install`
2. Run: `npm start` or `expo start`

## Features
- User authentication (register/login)
- CRUD for movies (using destinations table)
- Reservations (bookings)
